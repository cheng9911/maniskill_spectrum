# 对称迁移三臂实验视频解说

本文件是「对称迁移（symmetry-transfer）三臂实验」物理回放视频（21–23）的逐段解说，供你自行复制到 PPT 备注、演讲词或字幕。视频本体只带 phase 覆盖条（reach → grasp → lift → align_keyed → enter_key → unlock_yaw → circular_insert），不嵌入解说文字。

三臂都在**同一个 held-out 干预**（socket 轴向 yaw **+30°**，`d_axial=+0.524`，condition_id=4）下录制，唯一的差别是**几何**与**演示者的偏航行为**。数据来自 `phase_switch_symmetry_rollouts_rotated/`（每臂 3 个种子，视频用 seed_20260818 的首个成功 episode）。

## 三臂设计一览

| 臂 | 环境 | 几何 | 演示者偏航行为 | d_axial 的角色 |
|---|---|---|---|---|
| 21 Keyed asymmetric | `KeyedCircularPhaseSwitch-v1` | 矩形键 + 键门 + 圆形孔 | 键必须转到 +30° 对齐键门 | **物理相关**（清障前 relevant，清障后 irrelevant） |
| 22 Circular honest | `CircularPhaseSwitch-v1` | 圆杆 + 圆孔（无键/键槽） | 全程 0°，不转 | **规范对称**（gauge），纯无关 DOF |
| 23 Circular placebo | `CircularPhaseSwitch-v1` | 圆杆 + 圆孔（无键/键槽） | 对齐阶段固定 +15° sweep，随后 0° 直插 | 规范对称，但轨迹里有人为偏航 sweep |

**核心科学问题**：模型学到的「偏航相关性 1→0 切换」究竟是**物理真实的**（键门的几何约束，21 臂），还是**从轨迹统计里背下来的**（演示者恰好转了）。22 臂是干净的对称基线；23 臂是对抗性 control——轨迹里有偏航 sweep、但 sweep 与 d_axial 无关，用来排除「轨迹统计记忆」。

## 视频 21 — `21_keyed_asymmetric_yaw_p30.mp4`（键合非对称臂）

**几何**：peg 是矩形键杆，socket 入口是矩形键门，门下方是圆形孔。socket 键门绕轴向转了 +30°。

- **reach/grasp/lift（0–约3s）**：机械臂从侧面端到端抓取 peg 并提起，键保持 0°。
- **align_keyed（约3–5s）**：peg 的键转到 **+30°**，对齐旋转后的矩形门（俯视可见键的方位角从 0° 转到 +30°）。
- **enter_key（约5–8s）**：键保持 +30° 逐步穿过矩形门（3mm 增量直插）。
- **unlock_yaw（约8–10s）**：键越过门进入圆形孔，偏航自由度解锁，键从 +30° 转回 ~0°。
- **circular_insert（约10–13s）**：peg 以 0° 方位插入圆形孔到底。

**一句话**：因为几何上有键门，偏航相关性是**真实的**——清障前必须转到 +30° 对齐，清障后归零。这就是 `g_yaw(s)=1→0` 的物理来源。

（实测各相位 peg 轴向偏航中位数：align +22.8° → enter +30.0° → unlock +24.6° → insert +20.2°，即进入键门前确实转到 +30°。）

## 视频 22 — `22_circular_honest_yaw_p30.mp4`（对称 honest 臂）

**几何**：peg 是圆杆，socket 是圆孔（无键、无键槽），绕轴向旋转 +30° 后几何完全不变。

- **reach/grasp/lift**：同上，圆杆保持 0°。
- **align_keyed**：peg **不旋转**，方位角保持在 ~0°（d_axial=+30° 完全不响应）。
- **enter_key / unlock_yaw / circular_insert**：圆杆以 0° 方位直插到底，全程无偏航 sweep。

**一句话**：d_axial 是纯规范对称 DOF——socket 转了 +30° 但几何不变，演示者也不转，轨迹里没有偏航 sweep。这是「干净」的对称基线。

（实测各相位 peg 偏航中位数均 ≈0°（±0.4°），全程不转。）

---

## 视频 23 — `23_circular_placebo_yaw_p30.mp4`（对称 placebo 臂，关键 control）

**几何**：与 22 臂完全相同（圆杆 + 圆孔，无键槽）。

- **reach/grasp/lift**：圆杆保持 0°。
- **align_keyed**：演示者加入一个**固定的 +15° 偏航 sweep**（在 collar 上方完成，避开圆杆在紧配合孔内旋转时的卡滞），然后回到 0°。这个 sweep **与 d_axial 无关**——无论干预是 +30° 还是别的，sweep 都是固定的 +15°。
- **enter_key / unlock_yaw / circular_insert**：圆杆以 0° 方位直插到底（sweep 只在 align 阶段出现一次）。

**一句话**：轨迹里**确实有**偏航 sweep，但这个 sweep 对 d_axial **没有任何因果响应**。如果模型只是背「对齐阶段要转一下」，就会在这个臂上产生伪偏航响应；能区分「物理相关」与「轨迹统计」的模型（如 Pdiag）应在 22 臂和 23 臂上都学到 `g_yaw≈0`。

（实测 align 相位 peg 偏航中位数 +8.6°，即固定 sweep 的瞬态峰值在 +15° 附近，随后 enter/unlock/insert 回到 ≈0°。）

## 三臂对比怎么用（PPT 建议）

1. **并排三连**：21 / 22 / 23 同一时刻（phase 覆盖条同步）横向对比，看键的方位角——21 转到 +30°、22 恒 0°、23 只短暂 sweep 到 +15° 后回 0°。
2. **一句话结论**：`g_yaw(s)` 的 1→0 切换来自**键门的物理约束**（21），不是演示者习惯（23）也不是几何里有没有转（22）；三臂对照把「对称性学习」与「轨迹统计记忆」彻底分开。
