# 物理事件代理对齐：人类示教与规划器的过渡响应比较

结论：在本次离线运动学事件对齐下，真机组间姿态差异在高度最高点前已明显形成，仿真规划器的差异主要在之后形成。接近终端邻域时两者都接近 10°。这支持末端附近响应幅度的描述性一致，但不证明完整瞬态规律一致，也不能把过渡时序差异归因于物理规律不同。

## 实验与策略混杂

真机是人类示教，仿真是规划器生成。测得的响应同时受任务几何约束、执行策略、初始条件、阶段定义与噪声影响。事件对齐减少时间错位，不消除人类/规划器差异。当前数据无法将 domain 效应与 policy 效应分离。自由搬运期间何时开始旋转具有策略自由度；接近插入时的姿态对齐则受到更强几何约束。

## 固定的事件提取规则

- 数据：真机竖直 50 条、倾斜 61 条；仿真 baseline / pitch −10° / +10° 各 3 条，共 9 条。
- 四个锚点：夹爪闭合、高度最高点、首次持续进入终端 TCP 邻域、终端参考帧。
- 最高点：夹持后、首次进入邻域前，0.2 s 跨度中值滤波后的 TCP z 最大值；不等同于真实控制阶段结束。
- 主邻域半径 30 mm，敏感性 20 / 40 mm。持续观察跨度至少 0.15 s（真机 6 帧，仿真 4 帧）。
- 邻域中心来自每条轨迹自己的终端 TCP 平均位置；没有独立标定孔平面、接触或轴尖。真机终端使用已有释放前窗口，仿真使用 solver phase 6。
- 事件间做分段时间归一化，不使用姿态选锚点或做动态时间规整。此坐标不等同于冻结律的 solver-phase 坐标。
- 两域主统计量统一为两组平均单位手爪轴的夹角，CSV 中 seed=-1。仿真各 seed 的配对夹角单独保留为诊断。

## 主结果（角度）

| 锚点 | 真机组间夹角 [95% 点态 bootstrap 区间] | 仿真 −10° | 仿真 +10° |
|---|---:|---:|---:|
| 夹持起点 | 3.32 [2.78, 3.90] | 0.02 | 0.02 |
| 高度最高点 | 7.22 [6.06, 8.35] | 0.03 | 0.03 |
| 进入终端邻域 | 10.09 [9.33, 10.90] | 9.94 | 9.57 |
| 终端参考帧 | 10.34 [9.65, 11.06] | 9.90 | 9.46 |

真机终端这里为参考帧的组均值夹角 10.34°；此前 10.30° 使用整个终端窗口，统计口径不同。真机 bootstrap 重采样 episode 2000 次，假设 episode 可交换；不处理未知 session 聚类，不是同时置信带。仿真阴影为 3 个 seed 配对夹角范围，不是置信区间。

## 对 A / B 的判断

跨整个夹持—搬运—插入区间，群体响应曲线呈阶段变化，描述上更接近 A；仅看终端邻域之后，则更接近 B 的稳定幅度。但群体渐变可以由不同示范的调整时刻分散造成，不能据此断言每条示范都是渐进调整，也没有直接辨识出因果 P_real(s)。夹持起点已有约 3.32° 组间差异，提示基线/上下文差异不能忽略。

不能据此声称“仿真规划器瞬态规律已迁移到人类示教”，也不能据此否定几何约束可迁移。若要验证策略无关的过渡律，需要独立物理状态坐标（如轴尖相对孔口距离、接触事件）并考察更换仿真规划策略后的稳定性；仅重新拉伸时间轴不够。
