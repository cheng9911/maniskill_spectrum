# 竖直至倾斜：插入末段 TCP 的完整位姿变换

使用已有 Franka FK 的释放前稳定窗口：每条示范取位置均值和四元数旋转均值，再按 episode 等权平均。主结果保留既有 13 条倾斜校准示范及其最近拾取位置 nominal 匹配，48 条倾斜示范只作残差评价；没有把倾角固定为 10°，没有施加固定旋转中心约束。

## 变换约定

设 X0、X1 是机器人基座坐标下竖直/倾斜插入终端的 TCP 齐次位姿，则

```
Delta = X1 @ inverse(X0)
R_delta = R1 @ R0.T
t_delta = p1 - R_delta @ p0
X_predicted = Delta @ X_nominal
```

平移单位 m，左乘，列向量约定。不能直接拼接欧拉角差和位置差。`inverse(X0) @ X1` 是另一种局部坐标表达，不能当作基座系左乘变换。

主矩阵见 `delta_base_left_calibration13.txt/.npy`：

```
 0.9856805489 -0.1100526387  0.1277586482  0.0050915014
 0.1269914669  0.9829403888 -0.1330464557 -0.0570341632
-0.1109370218  0.1473655617  0.9828409680  0.0449928163
 0             0             0             1
```

完整旋转角 12.6487°，TCP 轴向倾斜 10.6899°。TCP 均值直接位置差为 [+3.369, −12.346, +2.030] mm，但矩阵平移列为 [+5.092, −57.034, +44.993] mm。前者是两个 TCP 原点的位移；后者考虑了基座原点附近表示的旋转，二者不能混用，也都不能不加条件地解释成孔口平移量。

## 何时可解释为孔变换

若每组终端都有相同的孔到 TCP 关系 H，即 X0=C0 H、X1=C1 H，则

```
X1 @ inverse(X0) = C1 @ inverse(C0)
```

在这个条件下，TCP 的完整差值就是孔在基座系下的相对变换。H 相同要求稳定抓取、相同插入深度、相同终端相对姿态以及可忽略的变形/滑移。对圆柱孔，孔并不约束轴向自旋，所以示教 TCP 的完整旋转可能含人类选择的额外 yaw；现有 TCP 数据不能唯一恢复这个孔轴自旋自由度。

因此输出为 **基于终端 TCP 的孔关系候选估计**，不是独立精确孔标定。另在 transform.json 中给出只对齐两根轴、取最小旋转的候选矩阵：该矩阵同样保留完整平移，但最小自旋是选择的约定，不是测得的孔 yaw。

## 三种结果分别用于什么

- `primary_calibration13`：沿用校准/评价隔离的主估计。
- `all_data_descriptive`：50 条竖直与 61 条倾斜示范的总体描述性估计，不适合再在同一批倾斜数据上声称独立预测。
- `single_nominal_episode0_to_calibration_mean`：把当前一条参考 episode 0 的终端窗口均值映射到校准倾斜组终端均值；矩阵另存 `delta_for_nominal_episode0.txt`。它包含该参考自己的示教偏差，不能与群体物理孔变换混为一谈。

13 条校准示范里 nominal 引用会重复；bootstrap 按校准配对抽样 2000 次，只是条件性离散度，不处理未知 session 聚类。矩阵各分量的区间见 transform.json。

## 对另外 48 条示范的终端残差

主矩阵作用于各自匹配的 nominal 终端后，平均位置误差 9.411 mm、完整姿态误差 6.193°、轴方向误差 3.322°。这表明人类示教、匹配和几何估计仍有明显离散；矩阵精确映射两个校准均值是构造性质，不是独立验证成功。

## 与此前生成轨迹的关系

本次不覆盖旧轨迹。旧轨迹使用固定 10°、有效固定中心的近似；本次变换允许独立平移和完整姿态变化。后续若用新矩阵生成阶段响应，必须明确 SE(3) 的基底与平移响应系数。现有单 pitch 冻结律不自动给出独立平移和 yaw 的传播规律；对整个新变换乘同一个 alpha 只能称为标量扩展假设。
