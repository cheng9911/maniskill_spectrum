## 当前不能报告规律一致的原因

1. 两组逐帧表格只有状态、动作、时间、索引，episode 表格主要是统计量和视频定位信息；没有显式孔位姿、已知干预向量、装配阶段或成功标记。
2. 仅观察机器人运动 X，无法同时确定未知输入 c 和响应算子 P。不能用成功终点反推孔位姿，再拿同一终点作为响应来证明 P 接近 1。
3. 即使确认第二组是固定 +10° 倾斜，也只有一个条件对比方向。基线和单一倾斜条件最多支持该方向的有限差分响应；无法单独识别五个 generator，更不能检验未施加的 yaw 干预。若伴随平移或抓取变化，只能辨识组合方向，不能拆成独立轴系数。
4. 111 条示范是记录数量，不意味着 111 个独立扰动条件。如果条件与采集场次完全重合，场次效应与条件效应混杂。不得把 94,752 帧当作独立样本。
5. 圆柱 yaw 对几何可行性不敏感，但操作者仍可能主动旋转物体。几何对称性本身不强制任意示范的 yaw 响应为零。需要匹配响应定义、抓取约束和示范生成准则。

`phase_switch_symmetry/benchmark_se3_transfer.py` 定义生成器 [du,dv,dw,roll,pitch,yaw]，圆柱 oracle 为 [1,1,1,1,1,0]，并按 solver_phase 分段重采样。oracle 是预设几何参照，不能冒充辨识出的 P_sim。正式检验应明确选取哪个已学习模型、训练条件与样本量，并冻结该选择。五维协议可选取 du、dv、roll、pitch、yaw，但不能混淆其与机械臂七个关节。

仿真使用孔的任务坐标、已知干预与物体姿态；真机需要通过经过确认的 Franka 运动学和末端到被夹物体的变换获得对应物体姿态。只有末端位姿而没有稳定抓取变换时，应限制为末端描述性分析。

## 正式分析的执行条件与方法

- 确认任务：两组是否相同圆柱轴孔；10° 的旋转轴、方向、参考坐标及旋转中心；是否同时改变孔位置、尺寸、抓取或机器人基座。
- 确认几何：每组或每条示范的独立孔标定、Franka 型号与关节零点、末端到物体变换。相机估计可用于提供几何，但必须保留标定与估计误差；不得宣称本次已有此信息。
- 标注阶段与结果：从视频或采集日志独立确认抓取、对准、接触和插入结束，排除回撤/复位段；记录成功及失败，保留所有排除理由。不能直接用整条示范末帧代表插入终点。
- 确定可辨识范围：已知 c 的设计矩阵决定可以分析哪些方向。混合干预检查秩和条件数；只有单侧 +10° 时报告有限差分，不把它称为零点导数。
- 对齐后比较：在相同任务坐标与归一化下计算物体响应。单一方向可用两条件的平均响应差除以已知干预幅度；旋转在共同参考下使用 SO(3)/SE(3) 相对变换，避免直接相减 Euler 角。正负干预齐备时才使用中心差分。
- 匹配幅度：10° 响应应优先与仿真在同样幅度下的有限变换预测比较，不将有限干预响应直接等同于局部导数或原始 alpha 对角元。
- 统计：按独立示范或场次进行相应重采样，保留配对结构；无场次信息时不宣称跨场次泛化。报告响应差、RMS 和最大绝对偏差及其不确定性；近常数曲线不使用 Pearson 相关作为主要指标。
- 一致性标准：结合任务容差、标定误差事先指定等效界限。未拒绝“有差异”不等于证明等效；当前无阈值，不给出 pass/fail。

如果现有数据只有一个受控倾斜方向，第一轮结果应命名为“轴线倾斜方向的局部一致性验证”。横向和平行轴 yaw 的选择性需要对应独立干预，不能通过多采同一条件的示范补足。
