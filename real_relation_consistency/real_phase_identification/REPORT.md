# 真机阶段识别：多信号候选、拒绝不确定分段、视频独立复核

已用全部 111 条 Franka 示范、94,752 帧实现可运行分段。当前能提供运动学阶段候选，不能宣称已精准识别接触/插入阶段，因为数据缺少独立阶段真值。推荐采用“自动提候选→视频盲标核验→固定阈值→因果在线监测”的流程，而不是将仿真阶段标签直接贴到真机上。

## 先明确真机的阶段含义

真机可观察的是：接近、夹持/抬起、搬运、装配接近/调整、轴向推进候选、末段稳定候选、释放。对圆柱孔没有证据支持单独设置仿真的 unlock 阶段。第一次接触必须单独标注；向下运动、速度变小和力矩变大都不单独等于接触。

识别器使用夹爪状态、Franka FK 的 TCP 位置/姿态、平移/角速度、相对目标 TCP 的距离、轴向与横向运动。原 action 后七维的范数和 robust z-score 仅作为未标定辅助负载特征保留；字段语义和力矩补偿未核实，没有据此判接触或输出 N 单位力。

## 固定规则

每个孔条件只用 episode_index%5==0 的示范估计目标 TCP 中心/轴（竖直10、倾斜13），另外88条不参与该参考估计。目标不是每条评价轨迹自己的末端，避免将“末段必然对齐自身终端”冒充可迁移识别。全数据此前已探索，仍属于回顾性分析。

| 事件 | 主规则 | 状态性质 |
|---|---|---|
| 夹持 / 释放 | 实测夹爪状态阈值与已有闭合区间 | 夹爪事件，不确认物体在爪内 |
| 抬起 | TCP 比夹持时高至少20 mm，持续至少0.15 s | 抬起代理，不确认脱离接触 |
| 装配接近 | 距参考终端 TCP 不超过80 mm，持续0.20 s | 几何邻域代理 |
| 轴向推进 | 距离≤60 mm、轴差≤5°、沿参考向下轴速度≥2 mm/s、横向速度≤20 mm/s，持续0.15 s | 推进候选，不等于进孔 |
| 末段稳定 | 距离≤20 mm、轴差≤5°、速度≤10 mm/s、角速度≤5°/s，持续0.30 s且与释放前窗口重叠 | 稳定候选，不等于成功 |
| 首次接触 | 暂无独立传感/人工标签 | 全部保留 unknown |

离线使用位置9帧 Savitzky–Golay、轴7帧中值、角速度7帧中值，包含未来样本；末段窗口也依赖释放后信息。因此该版本不能直接称为在线识别器。未满足事件规则时保留缺失和 unresolved，不强迫所有轨迹都有完整阶段。

首次末段稳定后若重新移动，逐帧标签退出稳定状态，回到 `post_settle_motion_unresolved`；连续重新稳定0.30 s才恢复稳定候选。这样不会把终端附近的停顿后运动整段误标为稳定。

## 数据实测覆盖与不确定性

| 自动事件 | 竖直 / 50 | 倾斜 / 61 | 合计 / 111 |
|---|---:|---:|---:|
| 夹持、抬起、接近区域、释放 | 50 | 61 | 111 |
| 轴向推进候选 | 49 | 55 | 104 |
| 末段稳定候选 | 49 | 54 | 103 |

101 条示范都有六个候选事件；10 条缺少一个或两个事件。这些是检出覆盖率，不是准确率。

严格阈值（轴3°/稳定15mm）、主阈值（5°/20mm）、宽松阈值（7°/25mm）下，推进候选检出数为79/104/111，稳定候选为68/103/110。55条示范的推进候选在阈值变化下偏移超过0.5 s；竖直、倾斜组的推进起点阈值时间跨度中位数分别约0.80/1.17 s。因此目前不能说 TCP 阈值已实现亚秒精准接触分段。

此外，竖直 episode 10、倾斜 episode 9 有稳定候选但推进候选缺失；它们保留这个不完整证据，未补造推进事件。各规则中未变化的阈值导致某些事件的敏感性跨度为零，不表示其真实时间误差为零。

有6条 head 视频的时长元数据与状态帧跨度不一致：竖直1、40；倾斜3、6、44、48。已标记，不能直接拿 nominal 帧率断言同步。

## 要实现“精准”，建议这样做

1. **先冻结有可观测定义的事件。** 夹爪闭合、物体离开支撑面、接近区进入、首次可见接触、持续轴向进入、最终就位、释放。接近区是预先设定的空间定义，不能让标注者凭感觉给几何阈值真值。
2. **独立看视频标时间区间。** 至少两名标注者先不看自动候选；模糊/遮挡的接触用区间或不可观察状态，不强求一帧精度。核对视频—状态同步，接触最好结合另一个视角。
3. **分开校准与评价。** 用标注校准子集确定阈值/持续时间/特征，锁定后在独立 episode/采集场次评价。当前默认候选不可反复按评价误差调优后仍称为留出评价。
4. **报告可测的精度。** 对可观察事件报告候选到人工区间的距离、±0.2/±0.5 s覆盖率、漏检率及人工区间宽度。误差统计注明仅对检出事件；覆盖率将漏检算失败。要报告帧级 F1 或假阳性率，还需完整帧级状态或不存在事件的标签。
5. **部署采用因果状态机。** 使用独立固定的目标坐标、过去样本滤波、滞回和最短持续时间，禁止读取未来释放或本次成功终点。接触/就位最好结合经核实的传感或外部成功信号，不能只根据“稳定”自动判断插入成功。

## 已提供的工具

针对当前“一条 nominal 装配参考”的实际路线，优先在所选参考上独立复核少数关键边界，再在其他 episode 上评价可重复性，不必先训练一个全任务 VLM。生成轨迹时保存每点的规划阶段和进度；执行时这个命令进度是已知的，在线识别器负责监测实际运动是否滞后、重新运动或未到达阶段条件。命令进度不能冒充物理接触，但也无需在线从零猜测每个控制阶段。真实圆柱任务中的稳定推进/插入区间可以与源中近似稳定响应的后段进行有说明的合并；不要伪造一个真实 unlock 事件。

- `events.csv`、`frame_labels/*.csv`：全部事件帧号、状态、特征和 unknown 接触标记。
- `sensitivity.csv`、`episode_audit.csv`、`event_coverage.csv`：缺失、阈值敏感性、视频时长问题；没有静默删数据。
- [全量阶段时间图](phase_timeline.png)、[特征示例图](phase_features.png)。时间图的灰色区间保留未解决的阶段，不是填充后的“完整真值”。
- [视频标注页面](review.html)：8条预选示范的剪辑，含原帧索引换算；默认隐藏自动候选，看过候选后导出的标注会记录暴露状态。8条仅是复核起步集，全部111条仍参与数值分析，不代表抽查已验证全部数据。
- `../evaluate_phase_annotations.py`：读取人工导出的JSON。默认只接受明确声明未看预测的标注；暴露/未知来源分开统计；无标签时不产生精度数字，并清除旧分数文件。
- `../real_phase_tracker.py`：仅依赖当前与过去观测的在线原型。已对全部111条数据回放：推进候选覆盖101条、稳定候选覆盖99条。它与离线事件回溯定义不同；这些同样不是准确率。输出 contact 和 insertion_success 始终 unknown，且稳定后运动会退出稳定状态。

离线候选和在线原型没有建立真实接触阶段与仿真 Align/Enter/Unlock/Insert 的一一对应。使用新六维规律前，需要选择与任务几何一致的相位映射，不能直接用归一化时间代替这个验证。
