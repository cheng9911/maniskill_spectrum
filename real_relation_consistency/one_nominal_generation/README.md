# 一条竖直装配参考：三处拾取连接 + 10° 倾斜预测

已生成离线 TCP 候选轨迹。这里的三处拾取运动由独立 waypoint 连接器生成，装配运动来自一条真实竖直孔示范，倾斜适应来自冻结仿真规律。没有下发机器人，也没有将生成曲线冒充真实执行结果。

## 使用的参考与几何

- 参考为竖直数据集 episode 0，按固定的首条规则选择，没有按倾斜预测误差挑选。仅使用它的真实运动作为参考。
- 共同装配起点取该示范夹持后、进入终端邻域前的高度最高点。它是自由空间入口的运动学代理，不是经标定确认的孔口/接触事件；参考段仍包含后续搬运、调整和插入。
- 共同起点 TCP（Franka 基座，m）：`[0.56646734, 0.03318134, 0.20569448]`，姿态见 manifest。
- 倾斜轴和有效中心沿用此前 13 条真实校准示范的 TCP 估计，输入角度 10°。因此“一条参考”指一条运动参考，不意味着整个几何估计只用了这一条示范。有效中心不是独立孔标定。
- 冻结规律未重新拟合；在当前源事件映射下起点 alpha=0，两个装配条件原本就具有同一个起点，没有人为把非零响应压成零。若更换参考入口或规律后 alpha 非零，脚本会停止而不是静默制造连续性。

## 三个位置

默认圆柱只平移，姿态、高度及夹持关系不变。以下是对应抓取 TCP 位置，不是圆柱中心坐标。

| 上下文 | 相对原圆柱位置变化 | 抓取 TCP x/y/z (m) |
|---|---|---|
| E1 | 不变 | 0.581049 / −0.082074 / 0.130732 |
| E2 | 基座 x +20 mm | 0.601049 / −0.082074 / 0.130732 |
| E3 | 基座 y +20 mm | 0.581049 / −0.062074 / 0.130732 |

这些是可替换的设计位置，没有声称它们是原数据的三个已标注位置或已验证可达的拾取位置。

每个连接段：抓取位正上方 50 mm → 下降接近（4 s）→ 闭爪事件保持（1 s）→ 垂直抬起（3 s）→ 平移并调整姿态（4 s）→ 共同入口（3 s）。搬运高度为抓取与入口两者较高 z 再加 50 mm；这是几何启发式，不是基于场景模型的避障规划。

位置使用五次时间插值，姿态使用同一时间规律的 Slerp，waypoint 处停稳。没有生成“机器人当前状态→首个接近点”的起始运动，首点必须由后续执行模块处理。闭爪标签不包含实际夹爪宽度、夹持力或成功传感确认。

## 文件怎么使用

- `E1_pickup.csv` / `E2_pickup.csv` / `E3_pickup.csv`：各自独立拾取连接，15 s、451 个 TCP 样本。
- `assembly_vertical.csv`：一条真实竖直装配参考的重采样轨迹。
- `assembly_tilt10.csv`：在同一参考上施加冻结仿真规律得到的倾斜装配轨迹。
- `E1_vertical.csv` / `E2_vertical.csv` / `E3_vertical.csv`：三处拾取＋完全相同的竖直装配。
- `E1_tilt10.csv` / `E2_tilt10.csv` / `E3_tilt10.csv`：三处拾取＋完全相同的倾斜装配。
- 六条组合轨迹均为 30 s、901 样本，30 Hz。连接处去除重复时间戳。
- CSV 字段：`time_s,x_m,y_m,z_m,qx,qy,qz,qw,stage`。位置为基座坐标下 TCP 的米单位，四元数顺序 xyzw、符号连续。stage 为语义标签，不是驱动指令。
- `assembly_response.csv`：原参考帧映射、事件进度、冻结系数、施加旋转及位置差值。
- `manifest.json` / `provenance.json` / `kinematic_checks.json` / `verification.json`：配置、哈希和数值检查。
- [轨迹图](generated_trajectories.png)：三处拾取连接、共享装配、旋转响应和位置偏移；另有 PDF/SVG/TIFF。

装配部分使用 15 s 的全局五次帧时钟，保留真实轨迹的内部几何变化；端点具有零速度时间规律，但没有抹去示范内的折线/噪声，因此不等于已经完成控制器所需的加速度、jerk 约束处理。

## 已核验与尚未核验

数值检查：三连接段精确汇合；同一条件下三个装配后缀逐点相同；竖直/倾斜轨迹入口位置及姿态一致；时间严格递增；四元数单位化及符号连续；倾斜结果符合有限 SE(3) 变换；冻结输入哈希保持一致。

当前组合轨迹的最大相邻样本线速度约 0.0875 m/s，角速度约 16.35°/s。这只是采样数值描述，不是速度安全认证或连续时间上界。尚未做逆运动学、关节限位、奇异性、场景/自碰撞、物体扫掠体、控制器加速度/jerk 和真实接触检查。因此 CSV 是 Cartesian 候选，不是可以直接播放到 Franka 的执行程序。

倾斜生成器也未被现有离线实验证明优于 identity。生成这些候选只证明计算流程可实现；实际插入是否成功仍要通过同等控制条件下的执行比较验证。
